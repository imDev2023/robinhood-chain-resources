== 12. Conclusion ==
Both addresses hold a real, verified UniversalRouter on chain 4663.
They were compiled from identical sources and their runtime code differs only in
immutables: the spokePool, the self address, and the domain separator derived from it.
Neither is a fork of the other and neither is modified.
0x8876...0904 is the genesis-era deployment with Across bridging disabled
(spokePool = UnsupportedProtocol) and it is what the SDK, the docs tables, the
Trading API and effectively all live traffic use.
0x06Af...bf99 is a 2026-07-06 redeployment of the same build wired to the live
Across SpokePool, and it is what deployments.json records.
The Bags docs' claim that 0x8876...0904 is a "Robinhood-modified fork" is false:
the source hashes and the byte diff both rule out any logic change.
