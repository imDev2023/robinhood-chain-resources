# Sunset of Blast Support (/docs/changelog/active-notifications/sunset-of-blast-support)

Posted: June 29, 2026

We are sunsetting support for the Blast network (chain id 81457) in Uniswap bridging and cross-chain flows.

**What is changing?**

Blast is being removed from bridging and cross-chain (chained actions) flows in the Uniswap apps and API. Blast is also being removed from the supported chains and deployment references in these docs.

**Why is this changing?**

Demand for Blast has decreased significantly, so we are ending support for these flows.

**What do I need to do?**

If your integration uses Blast for bridging or cross-chain (chained actions), move to a supported chain. The current list is available at [Supported Chains](/docs/trading/swapping-api/supported-chains).
