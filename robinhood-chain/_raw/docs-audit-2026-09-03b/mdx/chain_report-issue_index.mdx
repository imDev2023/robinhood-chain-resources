# Report an issue

This document provides an overview of how to report issues or questions for Robinhood Chain.

- To report technical issues, please contact us [here](mailto:chain-developers-group@robinhood.com).
- To report potential vulnerabilities, please submit a report [here](mailto:chain-developers-group@robinhood.com).
- To discuss partnerships, please contact us [here](mailto:chain-developers-group@robinhood.com).
