# Add network to your wallet[](https://docs.robinhood.com/chain/add-network-to-wallet#add-network-to-your-wallet)

## Robinhood Wallet[](https://docs.robinhood.com/chain/add-network-to-wallet#robinhood-wallet)

[Robinhood Wallet](https://robinhood.com/web3-wallet/) provides support for Robinhood Chain. To enable:

1.   Download Robinhood Wallet (requires iOS or Android)

[![Image 7: Download on the App Store](https://cdn.robinhood.com/assets/generated_assets/hoodchain_docsite/app-stores/apple-app-store.svg)](https://apps.apple.com/us/app/robinhood-wallet-swap-crypto/id1634080733)[![Image 8: Get it on Google Play](https://cdn.robinhood.com/assets/generated_assets/hoodchain_docsite/app-stores/google-play-store.svg)](https://play.google.com/store/apps/details?id=com.robinhood.gateway)

1.   Create a wallet

## Connect using a Browser Wallet[](https://docs.robinhood.com/chain/add-network-to-wallet#connect-using-a-browser-wallet)

Robinhood Chain is compatible with EVM Wallets (MetaMask and more). Click on your wallet below to automatically add Robinhood Chain.

Mainnet Testnet

Connect your wallet to add Robinhood Chain

Browser Wallet

### To add manually to MetaMask:[](https://docs.robinhood.com/chain/add-network-to-wallet#to-add-manually-to-metamask)

1.   In MetaMask, follow these instructions to add a network manually.
2.   Enter the details below:

| Property | Robinhood Chain | Robinhood Chain Testnet |
| --- | --- | --- |
| Chain ID | 4663 | 46630 |
| Default RPC URL | `https://rpc.mainnet.chain.robinhood.com/` | `https://rpc.testnet.chain.robinhood.com` |
| Currency Symbol | ETH | ETH |
| Block Explorer | [robinhoodchain.blockscout.com](https://robinhoodchain.blockscout.com/) | [explorer.testnet.chain.robinhood.com](https://explorer.testnet.chain.robinhood.com/) |
