# Add network to your wallet

## Robinhood Wallet

[Robinhood Wallet](https://robinhood.com/web3-wallet/) provides support for Robinhood Chain. To enable:

1. Download Robinhood Wallet (requires iOS or Android)

[![Download on the App Store](https://cdn.robinhood.com/assets/generated_assets/hoodchain_docsite/app-stores/apple-app-store.svg)](https://apps.apple.com/us/app/robinhood-wallet-swap-crypto/id1634080733)[![Get it on Google Play](https://cdn.robinhood.com/assets/generated_assets/hoodchain_docsite/app-stores/google-play-store.svg)](https://play.google.com/store/apps/details?id=com.robinhood.gateway)

1. Create a wallet

## Connect using a Browser Wallet

### To add manually to MetaMask:

1. In MetaMask, follow these instructions to add a network manually.
2. Enter the details below:

| Property | Robinhood Chain | Robinhood Chain Testnet |
| --- | --- | --- |
| Chain ID | 4663 | 46630 |
| Default RPC URL | `https://rpc.mainnet.chain.robinhood.com/` | `https://rpc.testnet.chain.robinhood.com` |
| Currency Symbol | ETH | ETH |
| Block Explorer | [robinhoodchain.blockscout.com](https://robinhoodchain.blockscout.com) | [explorer.testnet.chain.robinhood.com](https://explorer.testnet.chain.robinhood.com) |
