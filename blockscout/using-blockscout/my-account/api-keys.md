# API keys

> Blockscout API keys have moved out of My Account. Get a universal Blockscout Pro API key at dev.blockscout.com for your explorer requests.

API Keys are no longer located in the MyAccount section of an individual explorer. You can get a universal API key at [https://dev.blockscout.com/](https://dev.blockscout.com/).
