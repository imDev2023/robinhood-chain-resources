# Terraform Deployment for Polygon Supernets

> Provision Blockscout infrastructure with Terraform configuration files tailored for Polygon supernets, including new VPC or existing VPC deployment options.

Terraform config files are currently available for Polygon supernets deployment. Settings can be updated based on client infrastructure.

Examples include deployment for a new Virtual Private Cloud (VPC) instance and deployment within an existing VPC, where ec2 instances, database, security groups and load balancers are added to existing infrastructure.
