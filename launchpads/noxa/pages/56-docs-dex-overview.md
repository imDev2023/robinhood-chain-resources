Markdown Content:
NOXA DEX is available at [dex.noxa.fi](https://dex.noxa.fi/). It’s a Uniswap V2 + V3 fork with no contract modifications.

NOXA DEX is deployed on the following mainnet chains:

| Stable | 988 | gUSDT |
| Katana | 747474 | ETH |
| DBK Chain | 20240603 | ETH |
| Hyperliquid EVM | 999 | HYPE |

Classic constant-product AMM pools:

*   Simple liquidity provision
*   0.3% swap fee
*   LP tokens for liquidity providers
*   Battle-tested Uniswap V2 contracts

Concentrated liquidity pools:

*   Multiple fee tiers (0.05%, 0.3%, 1%)
*   LP NFTs
*   Higher capital efficiency

The contracts are **unmodified forks** of:

*   Uniswap V2 Core & Periphery
*   Uniswap V3 Core & Periphery

This means:

*   Audited, battle-tested code
*   Compatibility with existing tools
*   Exact same bytecode as canonical Uniswap deployments on Ethereum mainnet
