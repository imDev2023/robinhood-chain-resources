# Doppler Protocol Ecosystem 🚀

[](https://github.com/whetstoneresearch/doppler-sdk-legacy#doppler-protocol-ecosystem-)

[![Image 6: License: MIT](https://camo.githubusercontent.com/fdf2982b9f5d7489dcf44570e714e3a15fce6253e0cc6b5aa61a075aac2ff71b/68747470733a2f2f696d672e736869656c64732e696f2f62616467652f4c6963656e73652d4d49542d79656c6c6f772e737667)](https://opensource.org/licenses/MIT)

A suite of tools for interacting with the Doppler Protocol - liquidity bootstrapping protocol built on Uniswap.

## Deprecation notice

[](https://github.com/whetstoneresearch/doppler-sdk-legacy#deprecation-notice)

> 🚨 this repository and its contents are in the process of being deprecated.
> 
> 
> See the [Doppler SDK Alpha](https://github.com/whetstoneresearch/doppler-sdk-alpha), [Doppler Indexer](https://github.com/whetstoneresearch/doppler-indexer), and [Doppler Demo App](https://github.com/whetstoneresearch/doppler-demo-app) repositories for active development.
> 
> 
> [Learn more](https://docs.doppler.lol/resources/legacy-sdks-and-migration-guides/overview).
