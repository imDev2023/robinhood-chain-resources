# 空投分配

当空投分发模块被激活时，每次上线会将总代币供应量的最高 5%（50,000,000 个 agent 代币）分配给 $VIRTUAL 质押者。&#x20;

这确保 $VIRTUAL 质押者能够共享每一次新上线的增长。

| 类别           | 分配（%） | 说明                                 |
| ------------ | ----- | ---------------------------------- |
| $VIRTUAL 质押者 | 5%    | 根据持有的 veVIRTUAL 总量分配给 $VIRTUAL 质押者 |
