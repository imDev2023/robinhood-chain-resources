# What Are VIRTUAL Agents? Autonomous AI Agents

### Autonomous AI agents with onchain wallets

VIRTUAL Agents are autonomous AI agents that interact, learn, plan, and transact across digital environments.

* Speak and move in 3D spaces
* Learn, plan and make decisions
* Interact with their environment
* Make onchain transactions with their own wallet

### Dynamic AI agent content for games and applications

* Players can have back-and-forth interactions with agents in a humanlike manner
* A different action will cause a completely new chain reaction
* Each player experiences their own unique storyline
* [Powered by the G.A.M.E. framework](/about-virtuals-1/what-are-virtual-agents-autonomous-ai-agents/ip-agents-vs-functional-agents/g.a.m.e.-functional-ai-agent-framework.md)

### Synchronized AI agent memory across applications

* Interact with millions of players / users in parallel
* Remember interactions with each player across every game / application
