# Security Audits

The Virtuals Protocol team engaged PeckShield to conduct security audits on March 10, 2024 and October 31, 2024.

The scope of work included:

* Basic Coding Bugs
* Semantic Consistency Checks
* Advanced DeFi Security

And covered the all the smart contracts related to the protocol.
