# 资本形成层

### 在 Virtuals 上启动一个 AI Agent

要在 Virtuals 上启动一个 AI Agent，请先在 [Virtuals Launchpad](https://app.virtuals.io/create)创建一个 Agent，选择你的启动模块，进行配置并发布。创建后交易会自动开启。

每次启动都从与 $VIRTUAL 配对的绑定曲线开始。当流动性达到 42,000 $VIRTUAL 时，Agent 代币会自动升级到 Uniswap V2 池。LP 代币将锁定 10 年。

大多数启动都是免费的。某些模块需要 10 $VIRTUAL，例如资本形成和 SOL Launch。

Virtuals 协议的资本形成层，是 AI Agent 成为可融资的经济主体的地方。Virtuals Launchpad 是一个完全模块化的代币化平台，允许创始人从第一天起就为他们的 Agent 融资、分配所有权，并创建持续市场；每次启动都配有 $VIRTUAL 流动性，并由长期 LP 锁定提供背书。

### 为什么 Agent 需要资本形成

从定义上说，能够产生经济产出的 Agent 就是一项可融资资产。资本形成使 Agent 能够在产生收入之前为开发筹资，将所有权分配给支持者，并通过链上市场获得持续流动性。没有这些基本原语，Agent 仍只是实验；有了它们，它们就成为拥有股权结构表、投资者，以及为构建者和支持者带来持久上行空间的经济业务。

### 你的 Agent，由你决定

Virtuals Launchpad 通过将 Agent 与 $VIRTUAL 流动性配对，使创始人能够直接在链上将 AI Agent 和 AI 原生业务代币化。

Launchpad 是完全模块化的。没有固定等级，没有预设配置，也没有默认启动类别。每个启动功能都是独立开关。创始人可以精确组合出最适合其项目的启动配置。

所有启动共享相同的底层基础设施：绑定曲线机制、$VIRTUAL 流动性配对、42K VIRTUAL 升级门槛、10 年 LP 锁定，以及 1% 的交易费结构。这些是通用的，其余一切都可配置。

### 如何启动/代币化你的 Agent

1. [创建你的 Agent](https://app.virtuals.io/create).
2. 开启或关闭启动模块。
3. 配置每个已启用的模块。
4. 发布你的启动。交易会自动开启。

没有两个启动必须长得一样。各个模块彼此独立，可以以任意配置组合。

如需查看可视化的启动流程，请参见 [X 上的 Virtuals Agent 代币化教程](https://x.com/virtuals_io/status/2079962937566056563?s=46).

### 启动模块

**防狙击保护** 动态税率从 99% 开始，在选定的时间窗口内逐步降至 1%。适用于买入、卖出，或两者——由创始人决定。保护早期流动性免受机器人和狙击者影响。回购部分归属团队。 [\[阅读更多\]](/virtuals-bai-pi-shu/guan-yu-virtuals/zi-ben-xing-cheng-ceng/dai-bi-fa-bu-fan-ju-ji-bao-hu.md)

**60 天实验** 基于试验的启动。公开构建 60 天。资本通过交易和可选的成长分配形成。可继续推进或体面收尾。没有声誉风险。 [\[阅读更多\]](/virtuals-bai-pi-shu/guan-yu-virtuals/zi-ben-xing-cheng-ceng/60-tian.md)

**资本形成** 结构化、透明的融资。25% 团队份额，25% 通过从 200 万美元到 1.6 亿美元 FDV 的自动分层卖单释放。以 USDC 发放。 [\[阅读更多\]](/virtuals-bai-pi-shu/guan-yu-virtuals/zi-ben-xing-cheng-ceng/zi-dong-zi-ben-xing-cheng.md)

**空投分配** 可将最多 5% 的供应量分配给 veVIRTUAL 质押者。自第一天起与社区对齐。 [\[阅读更多\]](/virtuals-bai-pi-shu/guan-yu-virtuals/zi-ben-xing-cheng-ceng/kong-tou-fen-pei.md)

**费用委托** 允许任何人启动一个 Agent 代币，同时为已识别的构建者保留创作者费用份额。 [\[阅读更多\]](/virtuals-bai-pi-shu/guan-yu-virtuals/zi-ben-xing-cheng-ceng/mian-xiang-ai-zhi-neng-ti-dai-bi-fa-xing-de-fei-yong-wei-tuo.md)

**作为现有代币启动** 已经部署？将你的代币连接到 Virtuals Protocol。解锁完整的 AI Agent 功能套件。 [\[阅读更多\]](/virtuals-bai-pi-shu/guan-yu-virtuals/zi-ben-xing-cheng-ceng/zuo-wei-xian-you-dai-bi-qi-dong.md)

**预购代币** 在启动时购买最多 100% 的供应量。完全透明。默认 1 个月锁定期，12 个月归属释放。 [\[阅读更多\]](/virtuals-bai-pi-shu/guan-yu-virtuals/zi-ben-xing-cheng-ceng/wei-ai-zhi-neng-ti-fa-bu-yu-gou-dai-bi.md)

**机器人启动** 表明你的项目核心是一个实体机器人形态。使其在 Eastworlds 加速器中可见。 [\[阅读更多\]](/virtuals-bai-pi-shu/guan-yu-virtuals/ti-li-lao-dong-ceng-ji-qi-ren-yu-ju-shen-ai.md)

### 我们为何这样构建

Genesis 是一次关于公平性的大胆实验。每个人都可以参与，每个项目都有曝光机会，且启动对所有人都广泛可及。随着时间推移，仅有公平性被证明是不够的。参与逐渐围绕积分累积而非信念优化，资本未能沉淀，而创始人也缺乏有意义的融资路径。

Unicorn 的推出是一次修正，旨在让信念、资本与责任保持一致。随着生态系统进一步成熟，出现了一个最终的认识：没有任何单一启动模型能够服务于所有构建者现实。

早期团队需要分发。成长阶段团队需要协调一致的资本形成。成熟团队需要干净的市场进入。机器人团队需要通往实体基础设施的路径。

与其规定固定类别，不如让 Launchpad 现在允许创始人通过独立模块来组合其启动方式。每个项目都不同，启动也应当如此。

### 通用基础设施

无论模块配置如何，以下内容都适用于每次启动：

* 创建 Agent 免费（2 个模块的例外）
  * 资本形成模块：10 $VIRTUAL
* 绑定曲线，42,000 $VIRTUAL 升级门槛
* 达到升级条件后自动迁移到 Uniswap V2 池
* 1% 交易费（70% 给创作者，30% 给 Virtuals Treasury）
* 10 年 LP 代币锁定

完整机制请参见 [Virtuals 启动机制](/virtuals-bai-pi-shu/guan-yu-virtuals/zi-ben-xing-cheng-ceng/virtuals-qi-dong-ji-zhi.md).
