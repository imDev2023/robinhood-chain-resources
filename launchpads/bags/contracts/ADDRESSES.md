## Docs versus chain

- All twelve addresses in the docs address book (`pages/002-docs-robinhood-contracts.md`) match what the factory proxy returns for `hook`, `vault`, `weth`, `permit2`, `poolManager`, `positionManager`, `tokenImpl`, `bondingCurveBeacon` and `feeShareBeacon` (`_raw/api/rpc-factory-config.json`, `_raw/rpc/factory-state-2026-09-02.json`).
- The docs do not mention the v1 stack (`0x46aD...4D40`, `0x2083...6EcC`, `0x26e4...ab80`), which launched 314 tokens between 2026-07-12 and 2026-07-30 and whose graduated tokens still show as `v1` in the app's pulse feed (`_raw/api/api-evm-rh-pulse-2026-09-02b.json`).
- The docs say `creationFee` defaults to 0.02 ETH; the live factory returns 0 since block 8375410 (2026-07-13 04:20:53 UTC, `CreationFeeUpdated(0)` in `_raw/rpc/admin-events-2026-09-02.json`).
- No `Upgraded` event after deployment on the factory proxy or either beacon, so the implementations above are the originals (`_raw/rpc/admin-events-2026-09-02.json`, `_raw/blockscout/address-0x8DCE...-logs.json`, `address-0xdFf0...-logs.json`).
