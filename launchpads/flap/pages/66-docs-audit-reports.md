# Audit Reports

* The Flap Launchpad Protocol V2, V4 and Flap Tax Token V1 were audited by Certik. Check the audit report on[ Certik Skynet](https://skynet.certik.com/projects/flap).
* Flap Tax Token V1 (Part of the V4 Protocol) passed a comprehensive security audit by BlockSec.
* Flap Launchpad Protocol V5 (including Flap Tax Token V2 and Flap PreLaunch V1) passed a comprehensive security audit by BlockSec.
